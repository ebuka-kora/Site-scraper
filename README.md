# Website with Web Scraping Functionality

## Overview

This is a full-stack web application that includes web scraping capabilities. The project is structured with separate frontend and backend services, making it modular and maintainable.

## Project Structure

```
.
├── frontend/           # React frontend application
│   ├── src/           # Source code
│   ├── public/        # Public assets
│   └── build/         # Production build
├── backend/           # Node.js backend server
│   ├── routes/        # API routes
│   ├── utils/         # Utility functions
│   ├── scraped/       # Scraped data storage
│   └── server.js      # Main server file
```

## Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

## Getting Started

### Backend Setup

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm start
   ```
   The backend server will start running on http://localhost:3000 (or your configured port)

### Frontend Setup

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
   The frontend application will start running on http://localhost:3000
